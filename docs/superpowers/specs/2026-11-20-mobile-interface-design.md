# 手机界面与桌面风格统一

用户已确认整体优化方案：手机采集、监控、记录页沿用桌面 FlClash 配色、圆角卡片、正常中文字体和浅深色外观。

## 视觉与结构

使用已有 `--fl-*` 颜色，不另建品牌配色。页面保留简洁标题、设备状态、视频区、任务表单与三个底部入口。卡片采用 24px 圆角，内部分组采用 14–18px 圆角；手机侧边留白 16px，常用触控入口至少 44px。普通说明文字不小于 12px，表单文字 16px，避免手机输入缩放。移除原装饰网格、强负字距和大量等宽小字。

视频复用已有 console 展示：明确加载、失败、重试、全屏及帧指标，失败时不显示破图。采集表单保持名称、备注、间隔、时长及原操作语义。监控使用清晰的资源卡片，保留底盘、巡航和急停入口；记录页保留翻页、重试、删除确认与图片查看。

主题选择与电脑端共用组件，保留 localStorage 的 app-theme 及 system/light/dark 语义；登录页也可切换。底部导航和急停为内容留出安全区，320–760px 页面无水平溢出，滚动到底后末项可见。

## 边界与验证
