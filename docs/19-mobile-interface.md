# 手机界面调整（2026-11-20）

采集、监控、记录和登录页统一使用电脑端 FlClash 颜色角色及圆角表面。常规中文字体替代装饰性等宽小字；表单、状态分组、底部导航和监控急停分别整理层级及安全区。手机外观入口与电脑端共用 `ThemeSelector.tsx`，保留 `app-theme` 的跟随系统、浅色和深色设置。

手机视频直接复用电脑端的 console 展示，失败时隐藏损坏图片，显示说明、重新连接和全屏入口。设备 API、车辆操控、采集、巡航心跳、轮询及安全判断未改变。
