# 小车控制台界面规范

配色、常用图标和资源曲线以 FlClash 默认主题源码为准：默认种子 `#007AFF`，vivid 配色，按同一规则生成浅色与深色。保留现有 React 业务接口、数字动效与实车控制逻辑。主题计算只在开发时运行，不增加前端运行时依赖。

## 布局与视觉

- 五个桌面工作区共享侧栏：菜单高度 54px、圆角 13px，切换时品牌区、菜单位置及说明显隐保持一致。
- 实时监控顶部为设备连接、CPU、内存和电池概览。模型状态位于视频工具栏，控制模式位于车辆操控标题下，原有信息和操作入口保留。
- 双光视频与操控区并排，模型操作位于视频下方；较窄屏幕逐步上下排列。输入源与违停参数通过检测设置弹窗编辑，控制回执按需展开。
- 系统诊断顶部展示 CPU、内存、GPU 运行趋势，下面集中底盘状态、运行摘要及云台操作。
- 正文沿用本机 Noto Sans CJK SC 等中文字体；数值采用等宽数字特性。页面标题 28px/500，区域标题 16px/600，主要数字 24–32px/500，说明 12–13px。
- 背景、表面、文字、状态色均取自生成的 FlClash 颜色角色；仪表卡片圆角 32px、内部区块圆角 20px。减少彩色图标底块及嵌套填充，蓝色用于主要操作，状态色用于真实在线与告警信息。
- 支持跟随系统、浅色和深色；旧暖灰配置迁移至跟随系统。手机继续使用原现场操作界面。

## 数字与曲线

`DataMotion.tsx` 为 CPU、内存、GPU、算法数量及媒体记录总数提供数值过渡。进入或重新点击工作区时，数字在约 1600ms 内从零递增至当前值；后续数据在约 700ms 内从上次显示值平滑变化到新值。取消了卡片上浮、整体位移、缩放和文字弹跳。

电池、控制状态、速度、坐标、模型 ID、PID 和时间等保持即时显示。动效不会重新挂载视频、清空模型选择或额外发送业务请求。系统减少动态效果设置下直接显示最终值。

`useResourceHistory.ts` 只收集收到的在线设备状态，按心跳去重，在内存中保留本次会话最近 60 次采样。`ResourceTrends.tsx` 使用这些真实采样绘制平滑曲线。无数据时显示等待；只有一个数据点时显示单点并继续采样，不填充虚构的历史曲线。曲线过渡时保持卡片位置与尺寸不变。

## 维护位置

- `src/desktop.css`：桌面基础样式与统一侧栏。
- `src/live.css`：实时监控布局和交互控件。
- `src/refinement.css`：统一字体、表面、资源图表与响应式细节，在基础样式之后引入。
- `src/components/LiveWorkspace.tsx`：实时监控的展示和事件绑定，原业务请求仍由 `App.tsx` 处理。
- 运行目录与仓库各自已有的视频连接、重连和帧监控实现分别保留。

## FlClash 主题与图标来源

- `src/flclash-theme.css` 与 `src/theme/flclash-tokens.json`：默认种子色的源规则生成结果；禁止另加自选品牌色。
- `src/flclash-surfaces.css`：原项目的表面层级、阴影、圆角，以及图表贴底展示。
- `src/components/FlClashIcons.tsx`：37 个从源码图形转换的常用 SVG 图标；5 个车辆专用图标保留原实现。SVG 圆角矩形与 Flutter 连续圆角的光栅结果存在细微差异。
- `ResourceTrends.tsx`：按上游 sigma=1.5 的平滑和 Catmull–Rom 路径绘图，线宽 2px、填充 14%；保持真实采样，不补造历史数据。
- `npm run generate:theme` 可重建颜色。生成器依赖 Material Color Utilities 0.4.0（开发依赖）。
- 源码版本、转换说明与 GPL/Apache 声明位于 `public/licenses/flclash/`。
